# 번역 용어표

`ko.json` 작성 시 이 표를 우선 적용. 기계 번역식 직역보다 **한국 maimai 커뮤니티 통용어**를 따름.

## 번역하지 않는 것

영문/약어로 굳어져서 한국어로 바꾸면 오히려 못 알아보는 것들.

```
DX  /  Standard  /  でらっくす
BASIC  ADVANCED  EXPERT  MASTER  Re:MASTER
SSS+  SSS  SS+  SS  S+  S  AAA  AA  A  BBB  BB  B  C  D
FC  FC+  AP  AP+
FS  FS+  FDX  FDX+
RATING  DX RATING
COMBO  SYNC
```

## 판정 등급

| 일본어 | 한국어 |

| PERFECT | 그대로 |
| GREAT | 그대로 |

## 표기 규칙

- 전각 괄호 `（）`, 전각 콜론 `：`, 전각 중점 `・`는 반각 `()`, `:`, `·`로 변환
- 숫자는 반각 (`１．０倍` → `1.0배`)
- 마침표: 원문에 있으면 유지, 없으면 붙이지 않음
- 존댓말/평서체는 원문 톤 유지. maimai NET은 대체로 `~합니다` 체
- 한 문장 안의 나열은 원문의 `、`를 `, `로

## 애매한 케이스

수집기가 뽑아준 `seen`(등장 경로) 필드를 보고 판단할 것.

- `確認` → 다이얼로그면 "확인", 목록 페이지면 "조회"
- `記録` → 명사면 "기록", 동사면 "기록하기"
- `設定` → 페이지 제목이면 "설정", 버튼이면 "설정"
- `選択` → 라벨이면 "선택", 버튼이면 "선택"

같은 원문이 문맥에 따라 다른 번역이 필요한 경우, 플랫 딕셔너리로는 구분 불가.
그럴 땐 해당 문자열만 페이지별 오버라이드 사전(`ko.overrides.json`)에 넣고
`location.pathname` 기준으로 우선 적용할 것. 남발하지 말고 정말 필요한 것만.
